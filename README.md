## MongoDB-RAG EVALUATION

This repository implements a Retrieval-Augmented Generation (RAG) system for MongoDB databases and provides an evaluation framework for benchmarking multiple Large Language Models (LLMs). The system uses LangChain and LangSmith to evaluate LLM performance when interacting with unstructured and document-oriented NoSQL data.

The benchmark evaluates each model using semantic accuracy, correctness, error rate, and latency metrics, providing a comparative analysis of LLM performance for MongoDB-based RAG workflows.
